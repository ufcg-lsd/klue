# Dependencies

To set up the environment for this project in a different kind of cluster, ensure the following dependencies are installed in your system:

1. **Minikube**  
    Install Minikube by following the [official installation guide](https://minikube.sigs.k8s.io/docs/start/).

2. **kubectl**  
    Install the Kubernetes command-line tool using [this tutorial](https://kubernetes.io/docs/tasks/tools/install-kubectl-linux/).

3. **Helm**  
    Install the Kubernetes package manager by following [this guide](https://helm.sh/docs/intro/install/).

4. **Docker**  
    Install Docker Engine by following [the official instructions](https://docs.docker.com/engine/install/ubuntu/).

5. **Python 3 Libraries**  
    Install the required Python libraries using the provided `requirements.txt` file:
    ```bash
    pip install -r requirements.txt
    ```
